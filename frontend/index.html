    About brightness & data quality

    Preview excludes bits 1, 2, 6, 9, 15 and 19. Other bits are retained as quality information. Missing FLAGS means finite-only selection in Preview.

    Multi-epoch uses a stricter policy: only SOURCE and FULLSAMPLE masks declared by each FITS header are allowed. All other set bits, including unknown bits, exclude the pixel before reprojection. The propagated flags_or field must be interpreted with valid_mask and weights. These are project display policies, not a photometry recommendation.

    The definitions below are from the official IRSA image documentation. Each loaded frame retains its header definitions internally; Observation Details summarizes scientific status and warnings. New or changed release definitions require verification; unlisted bits have no assumed meaning here.
